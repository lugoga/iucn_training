# Day 5: Reproducible Research & Project Delivery

Today is the final day of the bootcamp, focusing on integration. We will learn how to write narrative text, execute code, display formatted tables, and embed figures together inside a single **Quarto (`.qmd`)** document. 

In the afternoon, each Theme Table will present their reproducible R project workflow using their own data or simulated theme data.

## Objectives
By the end of today's sessions, you will be able to:
1. Construct and compile a Quarto document (`.qmd`).
2. Style reports using Markdown headers, lists, links, and math equations.
3. Configure code chunk parameters (`echo`, `warning`, `message`, `tbl-cap`, `fig-cap`).
4. Render documents directly to Microsoft Word, PDF, or HTML formats.
5. Apply professional styling using document layout presets.
